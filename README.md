# Neova Studio

Neova Studio is a desktop companion for working with a team of AI agents: tasks, goals, a shared wiki, group chat and agent terminals in one place.

**Download:** [latest release](https://github.com/RemcoMagielse/neova.studio/releases/latest) · **Docs:** [neova.studio](https://neova.studio)
